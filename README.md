# ⚡ NEXUS
### Autonomous Blockchain Intelligence & Evidence-Based VASP Attribution Agent

NEXUS is an intelligent blockchain investigation platform that combines **Ethereum blockchain intelligence** with **TinyFish-powered web research** to support evidence-based identification and attribution of Virtual Asset Service Providers (VASPs).

The project aims to connect on-chain activity with relevant external information, helping transform blockchain investigation into a more structured and evidence-driven process.

## 🎯 Project Objectives

- Analyze blockchain-related information from Ethereum.
- Gather relevant information using TinyFish.
- Support evidence-based VASP identification and attribution.
- Connect blockchain intelligence with external research.
- Organize investigation findings for better understanding.

## ✨ Key Highlights

- **Blockchain Intelligence:** Ethereum-focused investigation.
- **Web Research:** TinyFish-powered information gathering.
- **Evidence-Based Attribution:** Support VASP identification using collected evidence.
- **Integrated Platform:** Frontend and backend components.
- **Modular Design:** Separate project components for maintainability.
